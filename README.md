# Artificial Intelligence Lab Exercises

Coursework exploring search, constraint satisfaction, graph data, and introductory AI concepts through Python and Jupyter-based exercises.

## Contents

- `LAB 2/adversial-serach.py` — Tkinter Tic-Tac-Toe using minimax
- `LAB 2/backtrack.py` — interactive graph-coloring exercise
- `LAB 2/csp.py` — constraint-satisfaction graph coloring with backtracking and MRV selection
- `LAB 3/network_generator.ipynb` — a Python script that generates a synthetic research-paper network; the historical filename uses an `.ipynb` extension even though its contents are plain Python
- `lab 4/first.ipynb` — notebook exercise using the included synthetic research-paper dataset

## Run

The Tkinter exercises use only Python's standard library:

```bash
python "LAB 2/adversial-serach.py"
python "LAB 2/backtrack.py"
python "LAB 2/csp.py"
```

The GUI exercises require a desktop environment with Tk support. Open the real notebook in Jupyter. Run the Lab 3 generator as Python with `python "LAB 3/network_generator.ipynb"`; its generated data is synthetic coursework data, not a real citation dataset.
